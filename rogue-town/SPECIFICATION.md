# Rogue Town 仕様書

## 1. 概要

Rogue Town は、街の中でプレイヤーを移動させながら、一定範囲内の敵を自動攻撃して倒す Canvas 製のブラウザゲームです。

- 実行方式: `index.html` をブラウザで開いて実行
- 画面サイズ: 960 x 600 px
- 外部ライブラリ: 使用しない
- 主な勝利条件: 2 分後に出現するボスを倒す
- 敗北条件: プレイヤーの HP が 0 以下になる

## 2. 操作

### 移動

初期設定は次の通りです。

| 方向 | 初期キー |
| --- | --- |
| 上 | W |
| 下 | S |
| 左 | A |
| 右 | D |

- 画面上の「上・下・左・右」ボタンを押すと、対応するキーを変更できる。
- ボタンを押した後に任意のキーを入力すると、そのキーを割り当てる。
- すでに別方向に割り当てられているキーは重複登録できない。
- 矢印キーやスペースキーも割り当て可能。
- 設定は `localStorage` の `rogueTownMoveKeys` に保存される。
- 保存設定は同じブラウザ・同じ端末で次回アクセス時に復元される。

### ポーズ

- スペースキーでポーズと再開を切り替える。
- 通常のポーズ中は、ゲーム内時間、敵の出現、攻撃、自動攻撃が停止する。
- ゲームオーバーまたはクリア後は、R キーでページを再読み込みして再スタートする。

### レベルアップ通知中

- レベルアップすると自動的にポーズする。
- 通常のスペースキーによるポーズ切り替えは無効になる。
- スペースキーを押すと通知を閉じてゲームを再開する。
- 通知中は、スペース以外のキー入力では解除されない。

## 3. プレイヤー

| 項目 | 初期値・仕様 |
| --- | --- |
| 初期位置 | キャンバス中央 `(480, 300)` |
| サイズ | 28 px の円 |
| 移動速度 | 3 |
| HP | 100 / 最大 100 |
| レベル | 1 |
| 初期 EXP | 0 / 次のレベルまで 50 |
| 攻撃力 | 20 |
| 攻撃範囲 | 150 px |
| 攻撃間隔 | 500 ms |

- プレイヤーは移動キーで 4 方向に移動する。
- プレイヤーは画面外に出られない。
- 攻撃範囲内で最も近い敵を自動的に狙う。
- 攻撃対象がいない場合は弾を発射しない。

## 4. レベルアップ

経験値アイテムを取得すると EXP が増加する。

- 必要 EXP の初期値は 50。
- レベルアップ後の必要 EXP は、現在値に 1.4 を掛けて小数点以下切り捨て。
- EXP が一度に複数レベル分たまっている場合は、複数回レベルアップする。
- レベルアップごとの強化:
  - レベル: +1
  - 攻撃力: +5
  - 最大 HP: +10
  - HP: 最大 HP まで全回復
  - 移動速度: +0.15

レベルアップ通知には次の内容を表示する。

- `LEVEL UP!!`
- `レベル: 変更前 → 変更後`
- `攻撃力: +5`
- `最大HP: +10`
- `HP: 全回復`
- `移動速度: +0.15`
- `スペースキーで再開`

## 5. 敵

### 通常敵

| 項目 | 仕様 |
| --- | --- |
| サイズ | 25 px |
| HP | 40 / 最大 40 |
| 移動速度 | 0.8 ～ 1.4 のランダム値 |
| 接触ダメージ | 継続的に `damage * 0.015` |
| 弾の発射間隔 | 3000 ms |
| 弾の速度 | 3 |
| 弾のサイズ | 6 px |
| 弾のダメージ | 8 |
| EXP | 10 |
| 色 | 赤 |

### ボス

| 項目 | 仕様 |
| --- | --- |
| 出現時刻 | ゲーム内時間 120 秒 |
| サイズ | 65 px |
| HP | 800 / 最大 800 |
| 移動速度 | 1.1 |
| 接触ダメージ | 継続的に `damage * 0.015` |
| 弾の発射間隔 | 1000 ms |
| 弾の速度 | 4.5 |
| 弾のサイズ | 24 px |
| 弾のダメージ | 16 |
| EXP | 100 |
| 色 | 紫 |

- 敵とボスは画面の上下左右いずれかの端からランダムに出現する。
- 敵はプレイヤーの現在位置を追尾する。
- 敵弾は発射時点のプレイヤー位置に向かって直進し、発射後は追尾しない。
- 画面外に出た敵弾は削除する。
- ボス出現後は通常敵の新規出現を停止する。

## 6. 弾とダメージ

### プレイヤー弾

- 攻撃間隔は 500 ms。
- 速度は 7。
- サイズは 7 px。
- 最も近い敵を追尾する。
- 対象の敵がすでに削除されている場合、弾も削除する。
- ボス弾に当たった場合、プレイヤー弾だけが消滅する。
- 通常敵の弾には相殺処理を適用しない。

### 敵弾

- プレイヤーに当たると弾を削除し、設定されたダメージを与える。
- 通常敵弾のダメージは 8。
- ボス弾のダメージは 16。
- プレイヤー HP が 0 以下になった時点でゲームオーバーにする。

## 7. 出現とゲーム進行

- 通常敵はゲーム開始後から定期的に出現する。
- 通常敵の出現間隔はゲーム経過時間に応じて短くなる。
- 出現間隔は `1500 - 経過秒数 * 6` ms を基準とし、最低 500 ms。
- ゲーム内時間が 120 秒になるとボスを 1 体出現させる。
- ボス出現時はゲームを一時停止し、`Boss has appeared !!` を表示する。
- ボス通知は 1000 ms 後に自動で消え、ポーズも自動解除する。
- ボス通知中のキー入力では解除されない。

## 8. 経験値アイテム

- 敵を倒すと、その位置に経験値アイテムを 1 個生成する。
- アイテムはプレイヤーが接触すると取得される。
- 通常敵のアイテムは EXP 10。
- ボスのアイテムは EXP 100。
- アイテムの表示サイズは 10 px、色は水色。

## 9. 画面表示

### フィールド

- 背景は緑色の地面。
- 中央に縦横の道路を配置する。
- 道路には白い破線を表示する。
- 四隅付近に建物を 4 棟配置する。
- プレイヤーは青、通常敵は赤、ボスは紫で表示する。

### HUD

キャンバス左上に次を表示する。

- HP と最大 HP
- Level
- EXP と次のレベルに必要な EXP
- プレイヤー HP バー

キャンバス右上に次を表示する。

- 経過時間
- ボス出現までの残り秒数、または `BOSS!`

### 通知画面

- 通常ポーズ: `PAUSED` と `スペースで再開`
- レベルアップ: 強化内容と `スペースキーで再開`
- ボス出現: `Boss has appeared !!`
- 敗北: `GAME OVER` と `Rキーで再スタート`
- 勝利: `TOWN SAVED!` と `Rキーで再スタート`

## 10. 勝敗

- プレイヤー HP が 0 以下になると `GAME OVER` を表示する。
- ボスの HP が 0 以下になるとボスを削除し、`TOWN SAVED!` を表示する。
- ゲームオーバー後・クリア後はゲーム更新を停止する。
- R キーでページを再読み込みすると最初から再開する。

## 11. 時間停止のルール

ゲームの進行は `gameElapsed` で管理する。

- 通常ポーズ中は `gameElapsed` が進まない。
- レベルアップ通知中も `gameElapsed` が進まない。
- ボス通知中も `gameElapsed` が進まない。
- そのため、ポーズ中に敵の出現、攻撃、ボス出現、自動攻撃のタイミングが進むことはない。
- 画面描画自体はポーズ中も継続する。

## 13. 変更時の確認事項

機能を変更した場合は、少なくとも次を確認する。

1. ブラウザでゲームを起動できること。
2. 移動、ポーズ、キー変更が動作すること。
3. 敵弾、ボス弾、プレイヤー弾の相互作用が仕様通りであること。
4. レベルアップ通知とボス通知の解除条件が正しいこと。
5. ゲームオーバーとクリア後に更新が停止すること。
6. キー設定がページ再読み込み後も復元されること。
7. 変更後に Git の commit と push が必要か確認すること。
